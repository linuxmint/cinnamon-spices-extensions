# Attribution

Active Window Highlight is based in part on **Active Window Indicator** by
`fabiodamio` (`active-window-indicator@fabiodamio`). In particular, the
trapezoid geometry, animated two-color gradient, default top-bar colors and
top-bar settings preserve that extension's design.

The original is distributed by Linux Mint in the GPL-2.0-licensed
`linuxmint/cinnamon-spices-extensions` repository. Its 64 × 64 icon is reused
here and remains credited to the original project.
