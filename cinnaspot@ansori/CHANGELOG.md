### 1.0.0

* Initial release of CinnaSpot (Spotlight-inspired launcher for Cinnamon).
* Added fast application search with relevance scoring and All Applications browser (`Ctrl + S`) with Grid/List views, sorting by Name/Category, and real-time filtering.
* Added opened windows sidebar with live clone thumbnail previews across workspaces.
* Added system info sidebar for real-time monitoring of CPU, RAM, Swap, and Disk usage.
* Added built-in mathematical calculator with expression evaluation and instant clipboard copying.
* Added support for system and session actions (Shutdown, Restart, Suspend, Logout, Lock Screen, Switch User) with confirmation prompts.
* Added script runner supporting custom shell (`.sh`) and Python (`.py`) scripts via configurable prefix (e.g., `sh`).
* Implemented multi-monitor support (spawns on the active monitor where the mouse cursor is located).
* Implemented clean tabbed settings layout (General, Windows, System Info, Appearance, Actions, Scripts).
