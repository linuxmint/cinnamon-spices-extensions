# Display Scale - Additional Features

Optional panel, desklet and OSD150 adjustments for the **Display Scale** applet.

- **Panel:** Keep panels and icons approximately the same size while the desktop grows. Optionally let panel text grow with the rest of the desktop.
- **Desklets:** Let desklets grow around their existing centers.
- **OSD150:** Keep an active OSD150 display positioned relative to the screen edges as it grows.

Install **Display Scale** in **System Settings → Applets → Download** and add it to the panel. Then download and enable this extension in **System Settings → Extensions**. Its controls are in the applet under **Scaling → Additional Features**. The extension waits for the applet before applying adjustments and releases its temporary changes when disabled.

Tested with LMDE 7, Cinnamon 6.6.9 and X11. The OSD position option applies when **OSD150** (`osd150@claudiux`) is enabled.

## Deutsch: Darstellungsgröße – Zusatzfunktionen

Optionale Erweiterung für das Applet **Darstellungsgröße**. Sie hält Leisten und Symbole beim Vergrößern ungefähr auf ihrer bisherigen Größe, lässt Desklets um ihren Mittelpunkt wachsen und passt die Position von **OSD150** bei Bildschirmvergrößerung an. Die Leistenschrift kann auf Wunsch mitwachsen.

Zuerst **Darstellungsgröße** unter **Systemeinstellungen → Applets** herunterladen und zur Leiste hinzufügen. Dann diese Erweiterung unter **Systemeinstellungen → Erweiterungen** herunterladen und aktivieren. Die Einstellungen stehen im Applet unter **Skalierung → Zusatzfunktionen**. Beim Deaktivieren nimmt die Erweiterung ihre vorübergehenden Anpassungen zurück.

Getestet auf LMDE 7 mit Cinnamon 6.6.9 unter X11. Die Positionsanpassung für die Lautstärkeanzeige setzt eine aktive **OSD150**-Erweiterung voraus.
